# {play} inbox

Drop anything here that you want on the {play} canvas: posters, illustrations, sketches, photos,
motion tests (video or gif), type studies. Any format, any size; originals are fine.

Name each file the way you want it captioned. This pattern is easiest:

    Title - Type - Year.ext        e.g.  Gramophone - Infographic - 2023.png

(Type and year are optional. If you skip them I will ask or leave the caption short.)

Then tell me "new things in the play inbox". I will shrink them to web size (webp / mp4),
move them to `assets/play/`, and add them to the canvas.

Keep out: anything already shown as a case study on the site, and anything under NDA.
This folder is ignored by git, so your big originals never get committed.
